# Licensing

## Source Code

- GPL-3.0.
- GPL-3.0 applies to source code in this repository, not automatically to voice recordings, voice model weights, rendered demos, or third-party assets.
- The project being a technical demo does not add extra non-commercial restrictions to GPL-licensed source code.

## Author Voice

- Separate from the source code license.
- Non-commercial mini-svs demo/testing/research use only unless written permission is granted.
- No resale, sublicensing, standalone voicebank/model redistribution, impersonation, or voice cloning outside mini-svs.

## Third-Party Voicebanks And Instruments

- Do not commit unclear-license assets to this repository.
- Prefer local user-provided paths.
- Verify each resource's own license before use.
- Include required attribution when a license requires it.
- Treat "publicly downloadable" and "open source code" as insufficient proof that an asset can be redistributed.
- Document required attribution for every bundled asset if bundled assets are added later.

## README Wording Rules

- README may recommend candidate resources, but must not imply that mini-svs grants permission for third-party voicebanks or instruments.
- README must keep user-facing licensing warnings concise and point detailed implementation rules to the spec files.
